## Commercial and disclosure boundary

Publication allows review only. It does not grant permission to copy, modify, distribute, sell, sublicense, train models on, or create derivative works from project materials. No investment right, publishing right, IP transfer, exclusivity, revenue share, delivery commitment, traction claim, or license is created without a signed written agreement.

## Current release blockers

Before any public playable release, the project must verify:

1. ownership and written assignments for all contributions;
2. dependency, artwork, audio, font, and AI-use provenance;
3. security, privacy, platform, and build-distribution readiness;
4. copyright inventory and trademark clearance;
5. approval of every disclosed screenshot, video, build, and commercial claim.
