# Security and Responsible Disclosure

This repository is a controlled public showcase. It should not contain production source code, credentials, private builds, personal data, confidential contracts, signing keys, tokens, or unreleased master assets.

## Reporting a concern

Do not publish suspected vulnerabilities, exposed secrets, private information, or bypass instructions in a public issue.

Send a concise report to: tokencraft1390@gmail.com

Include the affected public file or page, observed behavior, potential impact, and safe reproduction details. Do not access data that is not yours, disrupt services, or attempt persistence.

## Release security gates

Before a playable build is shared publicly, verify:

- secrets and debug data are absent;
- dependencies are locked and reviewed;
- permissions and network behavior are documented;
- analytics, accounts, payments, and data collection are disclosed;
- save files and user input are handled safely;
- distribution files are malware-scanned and integrity-checkable;
- reporting and update procedures exist.

No public build is currently represented by this showcase unless explicitly identified in the README.
