# Controlled Demo Instructions

No public gameplay build is currently listed in this repository.

When an approved limited build becomes available, this document will state:

- exact build name, version, date, and supported platform;
- official download location and integrity hash;
- installation and launch steps;
- what the demonstration proves and does not prove;
- known limitations;
- network, account, analytics, and data behavior;
- expiration or access restrictions;
- feedback and security-reporting channels.

A compiled demonstration should exclude source code, development credentials, private analytics keys, editable master assets, unreleased levels, debug menus, and unnecessary project metadata.
