# Approved Public Media

Only disclosure-approved media may be placed in this directory.

Before adding a screenshot, trailer, gameplay clip, logo, character image, song, or sound effect, record:

- file name and cryptographic hash;
- creator and creation date;
- source project or build version;
- ownership or license evidence;
- depicted third-party brands or content;
- whether confidential mechanics or narrative are exposed;
- written approval for public use;
- required attribution.

Editable master files, layered artwork, raw recordings, music stems, source project files, credentials, and unapproved assets must remain private.
